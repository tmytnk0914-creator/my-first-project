# 提出前チェックリスト(レポート・企画書・資料)

提出・送信の直前に、上から順に確認する。1つでも□なら提出しない。

## 数値(最重要)
- [ ] 合計・小計が元データと一致している
- [ ] 前月比・前年比の計算方向が正しい(増減の符号)
- [ ] グラフの数値とテキストの数値が一致している
- [ ] AIが生成した数値を元データと突き合わせた(**AIの数値は必ず検算**)

## 内容
- [ ] 結論が最初に書かれている
- [ ] 「(要記入)」「(要確認)」「(推測)」が残っていない
- [ ] 事実と意見(解釈)が区別できる書き方になっている
- [ ] 読み手が最初に聞きそうな質問への答えが入っている

## 体裁
- [ ] 誤字脱字チェック済み(prompts/文章推敲.md を使うと早い)
- [ ] 日付・宛先・自分の名前が正しい
- [ ] ファイル名が命名ルール(docs/02_運用ルール.md)に沿っている
- [ ] 表記ゆれがない(です・ます、全角半角)

## 安全(社外・共有前は必須)
- [ ] 社外秘の数値・情報が入っていない
- [ ] 個人情報(氏名・連絡先)の扱いが適切
- [ ] 共有範囲(宛先・リンク権限)が意図どおり
- [ ] 古いバージョンを添付していない

---
※このチェックリストは資料の種類に応じて項目を足して育てていく。
