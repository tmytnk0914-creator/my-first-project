# プロンプト: 企画書たたき台

```
あなたは経験豊富な企画職のアシスタントです。
以下のメモから、社内向け企画書の初稿を作ってください。

## メモ(雑でOK)
- やりたいこと: 【例: 新商品のSNSキャンペーン】
- 背景・きっかけ: 【例: 若年層の認知が低い】
- 予算感・期間: 【わかる範囲で。不明なら「不明」と書く】
- 読み手: 【例: 部長。数字を重視するタイプ】

## 出力形式(この構成を守る)
1. 企画名(キャッチーに3案)
2. 背景・課題(3行以内)
3. 提案内容(まず1文で言い切る→詳細)
4. 期待効果(仮の数値目標を置き、「仮」と明記)
5. スケジュール(表形式)
6. 必要リソース・コスト
7. 想定される反対意見と回答(読み手が突っ込みそうな点を3つ)

## 制約
- メモにない数値・事実は創作せず「(要確認)」と書く
- 専門用語を使いすぎない
- 全体でA4一枚に収まる分量
```
