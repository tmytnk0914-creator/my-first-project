# プロンプト: コンテンツ案出し

```
あなたはアイデア出しの壁打ち相手です。ブレストに付き合ってください。

## テーマ
【例: 30代向け新商品の販促コンテンツ】

## 条件
- ターゲット: 【誰に届けたいか】
- 媒体・形式: 【例: SNS投稿 / ブログ / 動画 / 社内資料】
- 避けたい方向性: 【例: 値引き訴求はNG】

## 出力形式
まず「王道案」を5つ、次に「変化球案」を5つ。
各案は以下の形式で:
- 案の名前(10字以内)
- 内容(2行)
- 狙い(誰のどんな感情を動かすか)
- 工数感(小/中/大)

最後に、あなたが一番推す案とその理由を1つ選ぶこと。

## 制約
- 実現不可能な案は出さない(予算・期間の常識の範囲で)
- 10案の方向性はできるだけ散らす(似た案を並べない)
```
