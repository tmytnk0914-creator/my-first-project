# 定型プロンプト集の使い方

ここにあるプロンプトは、Claude・ChatGPT・Copilot などどのAIでもコピペで使えます。

## 使い方(3ステップ)
1. 使いたいプロンプトのファイルを開く
2. `【 】` の部分を自分の内容に書き換える
3. AIに貼り付けて送信する

## プロンプト一覧
| ファイル | 用途 | 使う場面 |
|---|---|---|
| 企画書たたき台.md | 企画書の初稿生成 | 企画書をゼロから書き始めるとき |
| データ分析コメント.md | 数値からの気づき出し | レポートのコメントが思いつかないとき |
| 資料要約.md | 長い資料の要約 | 過去資料・参考資料を読む時間がないとき |
| コンテンツ案出し.md | 企画・コンテンツのアイデア出し | ネタ切れのとき、発想を広げたいとき |
| 文章推敲.md | 文章のチェックと改善 | 提出前の最終仕上げ |

## 良いプロンプトの型(これを覚えれば自分で書けるようになる)
すべてのプロンプトは次の5要素でできています:

1. **役割**: 「あなたは◯◯の専門家です」
2. **材料**: 分析・加工してほしいデータや文章
3. **タスク**: 何をしてほしいか(1つに絞る)
4. **出力形式**: 表で/箇条書きで/◯個/この構成で
5. **制約**: やってはいけないこと(数値を創作しない、など)

うまくいかないときは、たいてい **3(タスクが曖昧)** か **4(形式指定がない)** が原因です。
