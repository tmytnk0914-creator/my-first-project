# プロンプト: 文章推敲

```
あなたは編集者です。以下の文章を提出前チェックしてください。

## 文章
【ここに貼る】

## 読み手と目的
【例: 部長向けの報告書 / 顧客向けの案内文】

## 出力形式
1. 修正版の文章(全文)
2. 変更点リスト(何を・なぜ直したか)
3. 直せなかった懸念(内容の判断が必要で、私が確認すべき点)

## チェック観点
- 誤字脱字、表記ゆれ(です・ます統一など)
- 結論が最初に来ているか
- 一文が長すぎないか(60字超は分割)
- 読み手に合った丁寧さ・トーンか
- 曖昧な表現(「など」「いろいろ」「検討します」)の乱用

## 制約
- 意味・事実関係を変えない。数値は絶対に変更しない
- 元の文体を尊重する(別人の文章にしない)
```
