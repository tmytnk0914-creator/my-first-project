# 運用ルール(ファイル命名・保存・AI活用)

## 1. ファイル命名ルール

```
YYYYMMDD_種類_内容_版.拡張子
例: 20260702_週次レポート_6月4週_v1.xlsx
例: 20260710_企画書_夏キャンペーン_v2.pptx
```

- **日付が先頭** → 並べ替えるだけで時系列になる
- **版はv1, v2** → 「最終」「最終2」「本当に最終」を禁止
- 提出した版はそのまま残し、修正は次の版番号で作る(上書きしない)

## 2. フォルダ構成ルール

```
業務フォルダ/
├── 01_受領データ/     ← もらった生データ。ここは絶対に編集しない
├── 02_作業中/         ← 整形済みデータ、作りかけの資料
├── 03_提出済み/       ← 提出した最終版のみ
└── 99_ナレッジ/       ← 再利用できる過去資料・テンプレート
```

- **原則: 生データは読み取り専用。** 加工は必ずコピー(整形済みファイル)に対して行う
- `scripts/clean_data.py` はこの原則に従い、元ファイルを変更しない

## 3. AI活用の運用ルール(安全のための約束)

### AIに渡してよいもの / ダメなもの
- OK: 自分の作業メモ、構成案、公開済みの情報、匿名化済みデータ
- 要注意: 社内数値(社内ツールのAIのみ。会社のAI利用ポリシーに従う)
- NG: 顧客の個人情報、認証情報(パスワード・APIキー)、未公表の重要情報

### AIの出力を使うときの約束
1. **数値は必ず検算する**(AIは計算・転記を間違えることがある)
2. 固有名詞・日付は元資料と突き合わせる
3. 「それらしいが根拠のない文章」に注意。根拠を聞き返す
4. 外部への投稿・送信は、AIに任せず必ず自分の手で行う

### 破壊的操作の禁止
- ファイルの削除・上書き・移動をAIに任せるときは、対象を確認してから実行させる
- 迷ったら「まずコピーを作ってから」を徹底する

## 4. 週次のAI改善タイム(15分)

毎週金曜に15分だけ、以下を行う:
1. `/weekly-review` で今週のふりかえりを作る
2. 「今週、手作業で繰り返したこと」を1つ挙げる
3. それを `docs/01_自動化候補一覧.md` に追記する(次の自動化のタネ)

これを続けると、3ヶ月で「自分の業務のどこをAI化すべきか」が自分で判断できるようになる。
