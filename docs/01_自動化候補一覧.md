# 自動化・効率化 候補一覧(STEP 2・3)

対象業務: 企画・マーケ・制作 / データ整理・レポート作成が時間のボトルネック / Excel中心

## 候補一覧(15案)

### 1. データ整形スクリプト(clean_data.py)
- 改善案: Excel/CSVを渡すと表記ゆれ修正・重複削除・集計サマリーまで自動で行うスクリプト
- 解決する課題: データ整理・入力の手作業時間と転記ミス
- 期待効果: 1回30分〜1時間の整形作業が数分に(週数時間の削減)
- 作るもの: Pythonスクリプト+呼び出し用Skill
- 実装難易度: 低 / 所要時間: 1時間 / リスク: 低(元ファイルは上書きしない設計)
- 優先度: ★★★(最優先)

### 2. レポート下書きSkill(/report-draft)
- 改善案: データと要点を渡すと、決まった構成でレポート初稿を生成するSkill
- 解決する課題: レポートを毎回ゼロから書く時間
- 期待効果: 初稿作成が数時間→10分。人間は仕上げに集中
- 作るもの: Claude Code Skill+レポートテンプレート
- 実装難易度: 低 / 所要時間: 1時間 / リスク: 低(初稿はたたき台、必ず人間が確認)
- 優先度: ★★★(最優先)

### 3. 定型プロンプト集(prompts/)
- 改善案: 企画書・要約・データ分析・コンテンツ案などのコピペ用プロンプトを整備
- 解決する課題: 毎回プロンプトを考える手間、出力品質のばらつき
- 期待効果: どのAIツールでも同じ品質の出力が即座に得られる。AIスキルの「型」が身につく
- 作るもの: prompts/ 配下のMarkdownテンプレート集
- 実装難易度: 低 / 所要時間: 1時間 / リスク: なし
- 優先度: ★★★(最優先)

### 4. 提出前チェックリスト
- 改善案: レポート・企画書の提出前チェックリストを標準化
- 解決する課題: 数値ミス・誤字・体裁不備による手戻り
- 期待効果: 手戻り削減、レビュー時間短縮
- 作るもの: templates/ 配下のチェックリスト
- 実装難易度: 低 / 所要時間: 30分 / リスク: なし
- 優先度: ★★☆

### 5. ファイル命名・保存ルール
- 改善案: 日付+種類+内容の命名規則とフォルダ構成を標準化
- 解決する課題: 過去ファイルを探す時間、バージョン混乱
- 期待効果: 検索時間の削減、AIに過去資料を渡しやすくなる
- 作るもの: docs/02_運用ルール.md
- 実装難易度: 低 / 所要時間: 30分 / リスク: なし
- 優先度: ★★☆

### 6. 週次ふりかえりSkill(/weekly-review)
- 改善案: 週の実績メモを渡すと週次レポートの骨子とコメント案を生成
- 解決する課題: 週次レポートのコメント考案時間
- 期待効果: 週1時間→15分
- 作るもの: Claude Code Skill
- 実装難易度: 低 / 所要時間: 30分 / リスク: 低
- 優先度: ★★☆

### 7. 企画書たたき台の半自動化
- 改善案: 要件を箇条書きで渡すと企画書構成(背景→課題→施策→効果→スケジュール)を生成
- 解決する課題: 企画書の構成決めと初稿の重さ
- 期待効果: 初稿までの時間を1/3に
- 作るもの: prompts/企画書.md(→将来Skill化)
- 実装難易度: 低 / 所要時間: 30分 / リスク: 低
- 優先度: ★★☆

### 8. 過去資料ナレッジ化(要約・再利用)
- 改善案: 過去の企画書・レポートをAIで要約し「再利用できる部品集」を作る
- 解決する課題: 過去の成果物が再利用されず毎回ゼロから作っている
- 期待効果: 類似案件の初速が大幅向上
- 作るもの: 要約プロンプト+ナレッジ保存ルール
- 実装難易度: 中 / 所要時間: 2〜3時間(資料量による) / リスク: 低
- 優先度: ★★☆

### 9. 月次レポートの完全テンプレート化
- 改善案: 月次報告の構成・グラフ・コメント欄をテンプレート化し、データ差し替えだけにする
- 解決する課題: 月次資料を毎回組み直す時間
- 期待効果: 月次作業が半減
- 作るもの: Excelテンプレート+更新手順書
- 実装難易度: 中 / 所要時間: 2時間 / リスク: 低
- 優先度: ★★☆

### 10. グラフ自動生成スクリプト
- 改善案: 整形済みデータから定型グラフ(推移・構成比・前月比)を自動生成
- 解決する課題: グラフ作成の繰り返し作業
- 期待効果: レポートの図表作成が数分に
- 作るもの: Pythonスクリプト(matplotlib/openpyxl)
- 実装難易度: 中 / 所要時間: 2〜3時間 / リスク: 低
- 優先度: ★★☆(候補1が定着したら着手)

### 11. コンテンツ制作フローの半自動化
- 改善案: 企画→構成→初稿→チェックの各段階にAIプロンプトを組み込んだ制作SOP
- 解決する課題: 制作の属人化と初速の遅さ
- 期待効果: 制作リードタイム短縮、品質の安定
- 作るもの: SOP文書+段階別プロンプト
- 実装難易度: 中 / 所要時間: 2時間 / リスク: 低
- 優先度: ★★☆

### 12. データ入力フォーム化(ミニWebアプリ)
- 改善案: 手入力データをフォームで受けてCSVに落とすローカルWebアプリ
- 解決する課題: Excel直接編集による入力ミス・フォーマット崩れ
- 期待効果: 入力ミス削減、後工程の自動処理が可能に
- 作るもの: HTML1枚のローカルフォーム(CSVダウンロード式)
- 実装難易度: 中 / 所要時間: 2〜3時間 / リスク: 低
- 優先度: ★☆☆(入力フォーマットが固まってから)

### 13. ダッシュボード化(ミニWebアプリ)
- 改善案: 主要KPIをCSVから読み込んで表示するローカルダッシュボード
- 解決する課題: 数値確認のたびにExcelを開いて集計する手間
- 期待効果: 状況把握が一目で完了、レポートにも転用可
- 作るもの: HTML+JSのローカルダッシュボード
- 実装難易度: 高 / 所要時間: 半日 / リスク: 低
- 優先度: ★☆☆(Fable 5級の実装力がある今なら挑戦価値あり)

### 14. MCP連携による資料の自動収集
- 改善案: Google Drive等のMCP連携で、レポートに必要な資料をAIが自動収集・要約
- 解決する課題: 資料探しの時間
- 期待効果: レポート準備の前工程がほぼ自動化
- 作るもの: MCP接続設定+収集プロンプト
- 実装難易度: 中 / 所要時間: 2時間 / リスク: 中(アクセス権限の確認が必要)
- 優先度: ★☆☆(Google Workspace利用が増えたら)

### 15. QA自動化(データ検品スクリプト)
- 改善案: 提出前のExcelに対し、空欄・異常値・合計不一致を自動チェック
- 解決する課題: 目視チェックの漏れ
- 期待効果: 数値ミスの流出防止
- 作るもの: Pythonチェックスクリプト
- 実装難易度: 中 / 所要時間: 2時間 / リスク: 低
- 優先度: ★★☆(候補1の次の拡張として)

### 最初に着手する3つと理由
1. **データ整形スクリプト(候補1)** — 毎日発生する「データ整理・入力」に直撃し、効果が即日出る。リスクも最小。
2. **レポート下書きSkill+チェックリスト(候補2+4)** — もう1つのボトルネック「資料・レポート作成」の初稿時間を1/10にする。
3. **定型プロンプト集(候補3)** — あなたのゴール「AIスキルを身につけたい」に最も効く。良いプロンプトの型を毎日使ううちに、自分で書けるようになる。
