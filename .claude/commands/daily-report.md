# 日次レポート作成コマンド

今日の作業内容を集約して日次レポートを作成します。

## 手順

1. `docs/tasks/` フォルダから今日のタスクファイルを確認する
2. `outputs/` フォルダから今日の成果物を確認する
3. 以下のフォーマットでレポートを作成する
4. `outputs/daily-report-YYYY-MM-DD.md` として保存する

## レポートフォーマット

```markdown
# 日次レポート — [日付]

## サマリー
[今日の主要な成果を3行以内でまとめる]

## 完了タスク
- [タスク1] — [担当エージェント]
- [タスク2] — [担当エージェント]

## 進行中タスク
- [タスク名] — [進捗%] — [ブロッカーがあれば記載]

## 明日のアクション
- [ ] [タスク1]
- [ ] [タスク2]

## 気づき・メモ
[今日の学びや改善点]
```
