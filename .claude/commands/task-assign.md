# タスク割り当てコマンド

このコマンドは、入力されたタスクを分析して、最適なエージェントに割り当てます。

## 手順

以下のステップを実行してください：

1. ユーザーから受け取ったタスクの内容を分析する
2. `agents/` フォルダのエージェント定義を参照する
3. 最適な担当エージェントを選定する
4. タスクをMarkdown形式で `docs/tasks/YYYY-MM-DD-[タスク名].md` に保存する

## 割り当て基準

| キーワード | 担当エージェント |
|-----------|----------------|
| SNS、コンテンツ、広告、ブランド | Marketing Agent |
| 提案書、営業、顧客、商談 | Sales Agent |
| 議事録、会議、業務フロー、マニュアル | Operations Agent |
| 調査、市場、競合、トレンド | Research Agent |
| 戦略、優先度、全体方針 | CEO Agent |

## 出力形式

タスクファイルを作成した後、以下を出力する：

```
## タスク割り当て完了

- タスク名: [タスク名]
- 担当: [エージェント名]
- 優先度: [高/中/低]
- ファイル: docs/tasks/[ファイル名]
```
