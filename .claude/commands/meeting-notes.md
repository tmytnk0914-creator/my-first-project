# 会議メモ整理コマンド

会議メモや議事録の素材を受け取り、構造化された議事録を作成します。

## 手順

1. `$ARGUMENTS` または貼り付けられたメモを入力として受け取る
2. Operations Agent の定義（`agents/operations-agent.md`）を参照する
3. 構造化された議事録を作成する
4. `outputs/meeting-[会議名]-YYYY-MM-DD.md` として保存する
5. アクションアイテムを `docs/tasks/` にも個別ファイルとして保存する

## 特に重視すること

- **アクションアイテムの明確化**: 誰が、何を、いつまでに
- **決定事項の明記**: 「検討」と「決定」を明確に区別する
- **次のアクション**: 会議後すぐに動けるレベルまで具体化する
