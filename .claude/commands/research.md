# 市場調査・情報収集コマンド

指定されたテーマについて調査レポートを作成します。

## 手順

1. Research Agent の定義（`agents/research-agent.md`）を参照する
2. `$ARGUMENTS` で指定されたテーマを調査する
3. 調査レポートを作成する
4. `outputs/research-[テーマ]-YYYY-MM-DD.md` として保存する

## 調査の視点（デフォルト）

調査テーマに応じて以下の視点を適用する：

**市場調査の場合:**
- 市場規模と成長率
- 主要プレイヤー
- 顧客セグメントとニーズ
- 参入障壁

**競合分析の場合:**
- 競合の強み・弱み
- 差別化ポイント
- 価格帯・ポジショニング

**トレンド調査の場合:**
- 直近の変化
- 今後の見通し
- オリエンタルスパークへの影響
