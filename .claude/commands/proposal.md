# 提案書作成コマンド

顧客向けの提案書ドラフトを作成します。

## 手順

1. Sales Agent の定義（`agents/sales-agent.md`）を参照する
2. `$ARGUMENTS` から顧客情報・提案内容を読み取る
3. 提案書ドラフトを作成する
4. `outputs/proposal-[顧客名]-YYYY-MM-DD.md` として保存する

## 提案書に必須の要素

1. **顧客の課題の言語化** — 顧客が感じている痛みを代弁する
2. **解決策の説明** — 具体的にどう解決するか
3. **導入効果** — 数値・事例で示す
4. **実施スケジュール** — フェーズ分けで現実的なプランを示す
5. **価格** — ROIが分かる形で提示
6. **次のアクション** — 提案後すぐに動ける形で

## 使い方の例

```
/proposal 顧客: ABC商事、課題: 営業管理が属人化している、提案: CRM導入支援
```
