# データ整形Skill

## 手順

1. 対象ファイルのパスを確認する。渡されていなければ、ファイルの場所を1回だけ質問する。
2. まずファイルの先頭数行を読み、列構成をユーザーに1〜2行で報告する(いきなり処理しない)。
3. `scripts/clean_data.py` を実行する:
   ```
   python3 scripts/clean_data.py <入力ファイル>
   ```
   - Excelで複数シートがある場合は `--sheet シート名` を確認して指定する。
   - pandas/openpyxl が未インストールなら `pip3 install pandas openpyxl` を先に実行する。
4. 出力された `_サマリー.txt` の内容を読み、以下をユーザーに報告する:
   - 何行・何列になったか、何を削除・修正したか
   - **空欄が多い列、異常に見える数値**(最小・最大が不自然など)を「要確認」として指摘する
5. ユーザーが追加の集計(ピボット、グループ別合計など)を求めたら、pandasで追加処理し、結果を新しいファイルとして保存する。

## 絶対に守るルール

- **元ファイルは絶対に上書き・削除しない。** スクリプトもその前提で作られている。
- 既存ファイルを上書きする必要が出たら(--force)、必ず事前にユーザーへ確認する。
- 整形結果の数値の正しさは保証できないことを毎回一言添える。最終確認は人間が行う。
- 個人情報(氏名・メールアドレス・電話番号)を含む列を見つけたら、その旨を報告し、外部への共有に注意を促す。
