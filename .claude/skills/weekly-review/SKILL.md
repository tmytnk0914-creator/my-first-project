# 週次ふりかえりSkill

## 手順

1. 今週の実績・メモを確認する。渡されていなければ「今週やったこと・数値・気になったことを箇条書きで貼ってください(雑でOK)」と1回だけ依頼する。
2. 以下の形式でふりかえりを作成する:

```
# 週次ふりかえり(YYYY-MM-DD週)
## 今週の成果(3つまで。数値があれば必ず入れる)
## うまくいったこと・その理由
## うまくいかなかったこと・その理由(推測は「(推測)」と明記)
## 来週の最優先3つ(それ以外は「やらないことリスト」へ)
## AI活用メモ(今週AIに任せられた作業/来週AIに任せたい作業)
```

3. 「AI活用メモ」では、メモの中から**繰り返し発生している手作業**を見つけて、自動化候補として指摘する(docs/01_自動化候補一覧.md に追記を提案する)。
4. 完成した週報は `reports/YYYY-MM-DD_週次ふりかえり.md` として保存を提案する(reportsフォルダがなければ作る)。

## ルール

- 反省会にしない。「来週どうするか」に必ず着地させる。
- 来週の優先事項は3つまで。ユーザーが4つ以上挙げたら、絞る手伝いをする。
